# 10.0 — 第一个正式版

> 这版是 GitHub Release 的说明稿，可以直接贴到 Release 正文里。

**节奏伙伴 10.0** 是第一个对外定版。规模没变——仍然是**一个 html、零依赖、离线可用**——但这一版把试用反馈里的问题都收干净了，剩下的都是明确的取舍，不是缺陷。

## 这一版做了什么

### 和弦补到八格

`4536251` 原先七个和弦走完就回到开头，第八小节等于被截掉。现在补成
**IV–V–iii–vi–ii–V–I–vi**，小调那套补成 **iv–V–III–VII–ii–V–i–VI**。

第 8 小节落在 vi（半终止）而不是 I，是因为停在主和弦上整句就收尾了、接不回开头的 IV；
停在 Am 上回到 F 很顺地进下一轮。这是流行歌里最常见的八小节走法。

老存档里的七格自定义进行会**自动循环补到第八格**，听感不突变。

### 关掉的层不再假装在响

以前关掉某一层（比如沙铃），播放时它的格子照样跟着节拍亮橙闪动，实际一个音都不发。
选一套只开鼓组的风格（布鲁斯、摇摆、放克…）之后，特别容易误判成"这个音色坏了"。

现在关掉的层既不参与高亮，也不留残留；整组去色，**暖橙＝在响、灰＝没在响**。

### 翻页不再自己动

8.0 加过"播放时自动跟随当前拍翻页"，实际用起来是干扰：页面自己横移会把正准备点的那一格甩到屏幕外。
这一版撤掉了，导航条只由人操作。

## 相对 9.0 的完整变更

- 和弦条 7 格 → 8 格，`CUSTOM_LEN` 同步改成 8
- `4536251` / `m4536251` 各补第 8 个和弦（vi / VI）
- 四小节预设进入自定义槽仍按原长度循环填满，不空第 8 格
- 老存档的七格自定义进行自动补齐
- 导出提示改为「选 8 正好是一个完整循环」
- 390 宽手机上每格 44.6px → 38.6px，仍然点得准；320 宽无横向溢出

## 升级方式

**不用做任何事。** 覆盖 `index.html` 即可，存档格式向后兼容：

- 旧的七格自定义和弦进行会被自动补到八格
- 其余设置（节奏型、风格、音量、混响、收藏夹）原样保留

如果之前在 iOS 上「添加到主屏幕」，重开一次即可，不需要重新添加。

## 已知限制

- 移调范围 **±6 半音**，到 ±6 时音色发闷，这是相位声码器的固有代价
- **只导出 MIDI，不导音频**。要成品音频请把 MIDI 拖进 DAW 换音源
- 手机上**一屏只能看 2 拍**。16 格全貌请用横屏或电脑
- 一首 4 分钟的歌，移调处理在电脑上约 8 秒、手机上 20–40 秒；处理期间原调照播，算完无缝切过去

## 验证情况

- 390 / 320 宽下无横向溢出，翻页位移、跟页（手动）、拖拽涂格、撤销、存档往返、MIDI 导出均已回归
- 和弦高亮循环正确：第 8 小节亮第 8 格，第 9 小节回到第 1 格
- 主要在 Chromium 上开发和验证；iOS Safari 做了针对性适配，但没有在全部机型上逐一实测
